## 1. Perceivable

- [ ] Every meaningful image has descriptive `alt` text that conveys its purpose. Decorative images use `alt=""`. Icon-only buttons and links have an accessible name. (1.1.1)
- [ ] Text contrast is at least 4.5:1, or 3:1 for large text (18pt, or 14pt bold). Check hover, focus, disabled-adjacent, and dark-mode states. (1.4.3)
- [ ] UI component boundaries, focus indicators, and meaningful graphics have at least 3:1 contrast against adjacent colors. (1.4.11)
- [ ] Color is never the only way to convey information (errors, status, required fields, chart series). (1.4.1)
- [ ] Structure is expressed in markup: real headings in a logical `h1`→`h2`→`h3` order, lists as lists, tables with header cells, landmarks (`header`, `nav`, `main`, `footer`). (1.3.1)
- [ ] DOM order matches visual reading order. (1.3.2)
- [ ] The page works at 200% text zoom and reflows at a 320 CSS px viewport width without horizontal scrolling, except for data tables, maps, and code blocks. (1.4.4, 1.4.10)
- [ ] Layout survives user text-spacing overrides without clipped or overlapping text. (1.4.12)
- [ ] Content that appears on hover or focus (tooltips, menus) can be dismissed with Escape, stays visible while hovered, and does not hide other content. (1.4.13)
- [ ] The page is not locked to a single screen orientation. (1.3.4)
