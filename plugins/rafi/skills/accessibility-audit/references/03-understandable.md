## 3. Understandable

- [ ] `<html lang>` is set correctly, and `lang` is set on passages in another language. (3.1.1, 3.1.2)
- [ ] Focusing or changing an input never triggers an unexpected context change such as a submit or a redirect. (3.2.1, 3.2.2)
- [ ] Navigation and repeated components appear in the same order on every page. Components with the same function are named consistently. (3.2.3, 3.2.4)
- [ ] Help mechanisms (contact, chat, FAQ) appear in a consistent place across pages. (3.2.6)
- [ ] Information the user already entered in the same flow is prefilled or selectable, not requested again. (3.3.7)
- [ ] Authentication does not depend on a cognitive test. Paste and password managers work. Show-password is available. (3.3.8)
- [ ] Content is written in plain language, and unusual terms or abbreviations are explained where they first appear.
