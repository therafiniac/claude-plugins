## Appendix: Standards Referenced

- **WCAG 2.2** (W3C): Level A and AA success criteria. Criteria added in 2.2 include 2.4.11, 2.5.7, 2.5.8, 3.2.6, 3.3.7, and 3.3.8. Verify the current version rather than trusting this document indefinitely.
- **WAI-ARIA Authoring Practices Guide** (W3C): keyboard and role patterns for custom widgets.
- **axe-core** (Deque): the automated rule set behind the CI checks. It covers only part of WCAG, so manual checks remain required.
